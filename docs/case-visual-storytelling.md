# Case visual storytelling audit

All five results charts (portal-kpi, wallet-kpi, astoria-kpi, health-kpi, atlyx-kpi) were removed. The 22 original result statements are rendered by the existing compact CaseResults component. No outcome percentage was moved into research or interpreted as a completion share.

There are no confirmed stage shares, drop-off counts or baseline/final pairs in the current context/research source text. Atlyx mentions more than 10 scenarios and an average of 3–4 steps, but has no comparable baseline. These remain textual; no analytical chart has been invented. The reusable evidence renderer remains available for actual future measurements.

Shared comparison surfaces have no separators on desktop or mobile. Semantic tones are configured explicitly: problem/red, solution/green, neutral/grey, hypothesis/grey. SkyWallet versus Sky Capital remains neutral. The global cursor was removed; CaseCursor is unchanged.
