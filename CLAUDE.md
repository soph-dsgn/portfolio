## Commands

- `npm run dev` — dev server on :5173 (`.claude/launch.json` → `dev`)
- `npm run typecheck`, `npm run lint`, `npm run check:locales`, `npm run build` — run all four before reporting a change as done
- New UI strings go through `t()` and need a pair in `src/i18n/ru.json` and `src/i18n/en.json`

## Skills to reach for

- `frontend-design`, `unslop` — visual direction and removing templated/AI-looking UI
- `web-design-guidelines` — UI, accessibility and UX review
- `animate`, `review-animations`, `find-animation-opportunities` — motion work
- `vercel-react-best-practices` — React performance when writing or reviewing components
- `playwright` — browser automation from the terminal when the built-in browser is not enough
